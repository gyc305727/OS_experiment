# 实验1-过程记录

本文件只记录实验1的 checkpoint、阶段证据和报告同步素材，不是最终实验报告。最终实验报告由用户根据真实截图、命令输出和个人理解自行整理。

## 实验名称

操作系统实验1：独立的不依赖 Rust 标准库的可执行程序

## 推进规则

- 严格按 Step 1 到 Step 8 推进。
- 每完成一个 Step/checkpoint 后必须暂停，不得自动进入下一阶段。
- 暂停时必须输出 `REPORT_SYNC_BLOCK`。
- 用户将截图和素材同步进实验报告，并交给 ChatGPT 验收后，Codex 才能继续下一 Step。
- Codex 不直接维护最终实验报告文档。
- 未经用户明确要求，不执行 `git add`、`git commit`、`git push`。

## Step / Checkpoint 清单

1. Step 1 环境与仓库状态确认。
2. Step 2 创建普通 Rust 项目并验证 `cargo build` / `cargo run`。
3. Step 3 配置 RISC-V target，并改为 `no_std` / `no_main` / `panic_handler`。
4. Step 4 使用 `file`、`rust-readobj -h`、`rust-objdump -S` 分析二进制。
5. Step 5 添加 `_start` 并观察 `qemu-riscv64` 运行现象。
6. Step 6 实现 `sys_exit` 退出机制。
7. Step 7 实现 `sys_write`、Write Trait、`print!` / `println!`，并输出 `Hello, world!`。
8. Step 8 本地 Git 提交与提交记录确认。
